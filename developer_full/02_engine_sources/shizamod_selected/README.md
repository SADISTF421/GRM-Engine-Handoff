Grand Rendering Mod 2.0

Модифицированный движок для проекта GRM 2.0 на основе X-Ray Engine 1.0007rc1 (30.07.2007) для Visual Studio 2008 Service Pack 1.

Инструкция по сборке - http://stalkerin.gameru.net/wiki/index.php?title=Сборка_движка_X-Ray

Ссылка на VS2008 с патчем - https://232106.game4you.top/forum/viewtopic.php?t=12979

При сборке обязательно иметь диск (X:), на котором должны находиться папки SDK и trunk.

Также при сборке обязательно иметь папку "Microsoft DirectX SDK (June 2010)" в Program Files (x86)

Основные изменения геймплея:
- Усовершенствованный AI монстров и сталкеров (восстановлене функционала из сборок 2004-2006 годов)
- Билдовский интерфейс (худ, инвентарь, ПДА, драгдроп, окна торговли и обыска)
- A-Life симуляция жизни в оффлайне из сборок 2004 года
- Билдовская раскачка оружия
- Фонарики не гаснут на трупах
- Улучшенная физика тел и автомобилей (восстановление билдовского рагдолла)
- Расширенный функционал автомобилей (открываемые двери, руки на руле, багажник, рабочий пулемет)
- Рабочие турели

Изменения графики:
- Восстановленный R2 Render периода 2005 года (цветовая гамма, туман, детальный бампинг, хеми освещение)
- Эффект светового следа из сборки 1833 (опционально)
- Исправленный теневой купол на R2
- Каскадные тени от солнца из Зова Припяти (опционально)
- Правильный расчет теней от солнца на R2 (опционально)
- Тени от мелких объектов на R1
