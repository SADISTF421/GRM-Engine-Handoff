GRM — ВОССТАНОВЛЕННАЯ GIT-ИСТОРИЯ ДЛЯ РАЗРАБОТЧИКА

Это новый локальный репозиторий, составленный из доступных файлов. Это НЕ старый Git-репозиторий и НЕ оригинальные коммиты. Даты, автор и идентификаторы этих коммитов относятся к реконструкции, а не к первоначальной разработке. Ветка и порядок отражают последовательность выдачи доступных архивов, но не доказывают, что все они были установлены пользователем. Состояние установленной игры надо сверять по хэшам.

Ветки (каждая начинается с одной предоставленной базы):
- scripts-v3: исходные scripts.rar пользователя (ID 971652cf), затем частичные наборы V3.1, V3.2, V3.3 с фактической заменой файлов из каждого набора. Команда git log --stat --oneline scripts-v3 показывает, что менялось. V3.3 — последняя ВЫДАННАЯ версия из имеющихся, не гарантия текущих файлов игры.
- r2-focus: первоначальный shaders.rar пользователя и последовательные эксперименты: near focus, исправление X5561, усиление, отключение по приближению изображения. Это независимая ветка, НЕ часть истории установки scripts-v3. Последняя версия — оценка увеличения, не прямой сигнал прицеливания, и не отключается в бою.
- engine-references: архивная C/asm и другие материалы хуков, варианты gore и cleanup. Положены как исторические справочные файлы одним импортом, НЕ готовый перенос в C++ и НЕ одобренные патчи.
- main: предоставленная база scripts.rar + shaders.rar без поздних изменений.

Показать изменения конкретного этапа:
  git log --all --graph --decorate --oneline
  git show --stat gore-v3.3
  git diff gore-v3.2 gore-v3.3 -- gamedata/scripts/
  git show --stat r2-focus-aim
  git diff r2-focus-visible r2-focus-aim -- gamedata/shaders/
  git switch scripts-v3
  git switch r2-focus

Код скриптов сохранён ПОБАЙТНО, исходная кодировка в основном Windows-1251. Безопасный просмотр человекочитаемых сравнения, уже преобразованных в UTF-8 — каталог docs/diffs/. SHA256 показаны в docs/INPUT_SHA256.txt. Выборочные наборы не содержали всех файлов: надстройка сохраняет прежние базовые файлы, но это сконструированный снимок, не дамп установленной игры.

В комплекте ранее созданного большого handoff — полные исходные архивы пользователя, бинарные версии, логи и тесты. Этот Git специально мал и не дублирует PDB, DLL, видео и полный архив движка. История настоящих коммитов, файлы .blend и модели OGF не обнаружены. Не выдавать архивные эксперименты по рендеру за доказанное исправление: пользователь сообщил, что в текущей сборке растяжения отсутствуют. Не заменять файлы игры без сверки версий и полного бэкапа.

Репозиторий локальный. На GitHub он НЕ загружен. Рекомендуется закрытый репозиторий: здесь присутствуют пользовательские файлы сборки. Чтобы отправить все ветки и метки, после создания пустого репозитория вручную:
  git remote add origin <URL-репозитория>
  git push -u origin --all
  git push origin --tags
Пути в старых генераторах /data/grm могут требовать адаптации. Тесты-заглушки не являются проверкой в игре.
